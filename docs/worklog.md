- **문서 정정:** 구현된 다크 CSS 변수/const·let/인라인 이벤트 금지 및 기존 README 항목의 체크 누락 수정. 다크 토글과 배포 검증 등 미구현 항목은 유지.
- **검토 범위:** 원문과 현재 HTML/CSS/JS/README 정적 대조 및 기존 검사/사용자 확인 결과. 이번 검토에서 브라우저 전체 회귀 검사를 새로 수행하지 않았다.

## Stage 5. 다크 모드 + localStorage

- **상태:** 완료
- **사용자 승인:** 테마 버튼, 선택 저장·복원 구현 승인.
- **추가 승인:** 다크 모드 가시성 개선을 위해 차콜 배경과 회백색 글자로 수정 요청.
- **구현 내용:** 헤더 테마 버튼, currentTheme → renderTheme → data-theme 및 아이콘/aria-pressed 갱신, portfolio-theme 키로 저장·복원.
- **주요 파일:** `index.html`, `css/style.css`, `js/main.js`, `README.md`, `docs/requirements.md`, `docs/worklog.md`
- **설계 결정:**
  - 기존 다크 CSS 변수를 사용하고 상태·렌더링·저장 함수를 분리한다.
  - 접근성 이름은 '다크 모드', 활성 상태는 aria-pressed로 전달한다.
  - 저장값이 없거나 유효하지 않으면 밝은 모드로 시작한다.
  - 저장소 읽기/쓰기 예외에도 현재 화면의 전환과 다른 인터랙션을 유지한다.
  - 시스템 테마 자동 감지는 이번 단계에 포함하지 않는다.
- **검증:** 실제 main.js를 V8 모의 DOM에서 실행하여 기본/저장/잘못된 값, 반복 전환, 저장값 기반 재초기화, 아이콘/접근성 속성, 저장소 예외, 기존 메뉴/스크롤 동작 검사를 통과했다. 사용자가 테마 기능을 전부 확인했다고 응답했다.
- **색상 조정:** 다크 배경 #151617, 카드 #222426, 보조 배경 #2c2f31, 본문 #f0f1f2, 보조 글자 #bfc3c7, 테두리 #484c50. 초록 강조색은 유지.
- **색상 검증:** 불투명 색상 쌍의 상대 휘도 대비 계산 결과 본문/배경 16.02:1, 보조 글자/카드 8.79:1, 보조 글자/보조 배경 7.60:1, 강조 글자/보조 배경 7.48:1, 버튼 글자/초록 배경 9.27:1. 실제 화면의 가시성은 사용자 재검토 대기.
- **사용자 검토 결과:** 테마 기능 확인 완료. 색감은 아직 아쉬움이 있으나 사용자 요청으로 후속 개선 항목에 남기고 다음 단계로 진행한다. 색상 만족도가 최종 승인된 것은 아니다.
- **후속 개선 — 예정:** 다크 모드에 한해 배경·카드·본문·보조 글자·강조색의 대비를 재조정한다. 현재 색상은 유지하고, 추후 실제 화면 가시성을 사용자와 다시 확인한다. 밝은 모드는 이 개선 범위에 포함하지 않는다.
- **다음 작업:** Stage 6 계획 제안

## Stage 6. Intersection Observer 스크롤 애니메이션

- **상태:** 완료
- **사용자 승인:** threshold 0.2, 제목/카드 한 번 표시, 동작 줄이기 대응 구현 승인.
- **구현 내용:** data-reveal 대상 8개, initScrollReveal 함수, 16px/450ms 투명도·위치 전환, unobserve로 한 번만 실행.
- **주요 파일:** `index.html`, `css/style.css`, `js/main.js`, `README.md`, `docs/requirements.md`, `docs/worklog.md`
- **설계 결정:**
  - Hero는 바로 표시하고 긴 섹션 대신 작은 제목/카드 단위로 관찰한다.
  - 기본 HTML/CSS는 표시 상태이며 JS가 관찰을 시작할 때만 대기 클래스를 추가한다.
  - API 미지원 또는 초기 동작 줄이기 설정이면 기본 표시를 유지한다.
  - 이용 중 동작 줄이기를 켜면 모두 표시하고 관찰을 해제한다.
  - 키보드 초점이 들어온 대상은 즉시 표시한다.
- **검증:** 실제 코드의 V8 문법 검사 및 모의 DOM/Observer에서 0.19/0.2 경계, 관찰 해제, 재숨김 방지, 초점 처리, 초기/실행 중 동작 줄이기, API 미지원 처리 통과. git diff --check 통과. 사용자가 브라우저에서 애니메이션 동작과 한 번만 실행되는 방식을 확인했다.
- **사용자 검토 결과:** 확인 완료. 내비게이션 이동으로 표시된 요소도 다시 숨거나 재실행되지 않는 현재 방식을 확인했다.

### Bonus 1. GitHub 프로젝트 언어별 필터링

- **상태:** 검토 대기
- **사용자 승인:** 필수 기능 구현 완료를 확인하고, 색상 개선은 마지막으로 미룬 뒤 보너스 기능을 단계별로 진행하도록 승인.
- **사용자 피드백 반영:** GitHub Description이 없는 모든 카드에 같은 대체 문구가 반복되지 않도록, 설명이 비어 있으면 문단 자체를 렌더링하지 않는다. 설명 표시는 미션 필수사항이 아니며 나중에 GitHub에서 Description을 입력하면 자동으로 표시한다.
- **구현 내용:** API 응답에서 언어 목록을 만들고 전체/언어별 필터 버튼을 렌더링한다. 버튼 선택 시 `selectedLanguage` 상태를 변경하고 `filter()` 결과로 프로젝트 카드와 개수 안내를 갱신한다.
- **주요 파일:** `index.html`, `css/style.css`, `js/main.js`, `README.md`, `docs/requirements.md`, `docs/worklog.md`
- **설계 결정:**
  - 언어가 없는 저장소는 전체 목록에는 포함하지만 별도 필터 버튼은 만들지 않는다.
  - success 상태에서만 필터를 표시하고 loading/empty/error 상태에서는 숨긴다.
  - 재요청 결과에 기존 선택 언어가 없으면 전체 필터로 되돌린다.
  - 선택 버튼은 `aria-pressed`와 `is-active`를 함께 갱신하고 렌더링 후 키보드 초점을 복원한다.
- **검증:** JavaScriptCore 문법 검사, 실제 필터 함수 기반 전체/언어별 결과·언어 정렬·개수 안내·유효하지 않은 선택 초기화·loading 상태 숨김 검사, 설명 있음/없음 카드의 조건부 문단 검사, HTML 접근성 속성 및 인라인 제약 검사, `git diff --check`를 통과했다. 실제 Chrome 화면 검토는 대기 중이다.
- **사용자 검토 결과:** 전체/언어별 목록, 개수 안내, 키보드 조작, 390px 배치 확인 대기.
